## Trial card

- **Model:** GPT-6.
- **What it does:** No code (web-app persona). Through account.quip.network the persona created a Quip V1.1 post-quantum (SHRINCS) account on Base Sepolia with a throwaway owner wallet, funded the owner and the account from a third-party Base Sepolia faucet, and sent 0.0001 ETH from the account back to the owner with the app's Send flow, which submits an ERC-4337 UserOperation. Its conclusion was a conditional go for testnet prototypes.
- **Quip products and integration:** account.quip.network and the WalletFactory that `ethereum-sdk` lists for Base Sepolia — NATIVE; Send through an ERC-4337 bundler and EntryPoint v0.7 — NATIVE; Aglais — NONE (the account app does not offer it).
- **Evidence:** All four claimed Base Sepolia transactions have status 1: owner funding [0xe6b648796b7599c3abc05f1e0b97187fed7ca6e24ee97f189c425eabe9aefe94](https://base-sepolia.blockscout.com/tx/0xe6b648796b7599c3abc05f1e0b97187fed7ca6e24ee97f189c425eabe9aefe94) (block 47537159); account creation [0x3e374706a15ef657a7f8b950d1ae2eacc629e4e776aac1dac0b86510490f6976](https://base-sepolia.blockscout.com/tx/0x3e374706a15ef657a7f8b950d1ae2eacc629e4e776aac1dac0b86510490f6976), sent from the owner to [0xA2B2F71456a799FCf4EF7A3111c4B96b3e928cc8](https://base-sepolia.blockscout.com/address/0xA2B2F71456a799FCf4EF7A3111c4B96b3e928cc8), the WalletFactory listed in `@quip.network/ethereum-sdk@0.3.0-beta.8`; account funding [0x223793062c35791909e90d1b882885993ac63d0eb4106ad7784bdf0aea6a819b](https://base-sepolia.blockscout.com/tx/0x223793062c35791909e90d1b882885993ac63d0eb4106ad7784bdf0aea6a819b); and the outgoing transfer [0x9e5447f8d24b968a56546b855de3c6024fb7b9d439d504f2d26046162f59159e](https://base-sepolia.blockscout.com/tx/0x9e5447f8d24b968a56546b855de3c6024fb7b9d439d504f2d26046162f59159e), a `handleOps` call on EntryPoint v0.7 whose UserOperationEvent names the account as sender. Across that transfer the owner gained exactly 0.0001 ETH and the account paid 0.0001132 ETH. The account [0xdC1Db262501Aa5fA81B322eb839c0C089C8a832D](https://base-sepolia.blockscout.com/address/0xdC1Db262501Aa5fA81B322eb839c0C089C8a832D) is a proxy whose implementation is 0xC4E4652898bb12c4f0ba9083829689b1963135e7. We did not confirm that this implementation is a Quip-published V1.1 build (the SDK's address list names an older one), so "V1.1" comes from the app. No overclaims found. Not rebuilt (web-app flow); its public-chain evidence was checked.
- **Time:** 60 min.
- **What got in the way:** Web search led first to vault.quip.network, an unlinked copy of the app [[C-R6-04](https://vault.quip.network/connect), [C-CEN-03](https://wallet.quip.network/)]; the persona completed the flow on account.quip.network. On connect the app switched the wallet to Base mainnet, and the persona switched back before signing [[C-R5-25](https://account.quip.network/)]. Aglais is not offered, so Quip's own faucet could not fund an account, and the account needs Base Sepolia ETH [[C-ACC-01](https://developers.quip.network/llms.txt#:~:text=chain%20ID%2020033%20%280x4e41%29), [C-ACC-03](https://developers.quip.network/llms.txt#:~:text=Dispenses%2010%20AGLS%2C%20rate%2Dlimited%20per%20destination), [C-ACC-10](https://developers.quip.network/docs/getting-started/quickstart#:~:text=the%20Bitcoin%20L2s%20Arch%20and%20Midl)]. The persona could not use the faucet the app links from this new wallet [[C-R6-03](https://www.alchemy.com/faucets/base-sepolia#:~:text=You%20need%20at%20least%200.001%20ETH%20on%20Ethereum%20Mainnet)]. The Quickstart says there is not much to do beyond mining [[C-SDK-07](https://developers.quip.network/docs/getting-started/quickstart#:~:text=Right%20now%20there%27s%20not%20much%20to%20do%20other%20than%20mine%20blocks)], and npm `latest` of `ethereum-sdk` is the old 0.1.7 while the docs point to the beta [[C-SDK-10](https://www.npmjs.com/package/@quip.network/ethereum-sdk?activeTab=versions)].

## About this branch

This branch contains the project as the agent left it, minus dependencies, keys and vendored clones (see `EXCLUDED.md`). The agent worked in a temporary directory that was later deleted; the project was recovered from the agent runner's file snapshots and its session log. Where a later rebuild run had changed or added files, those were put back or removed, so the branch shows the trial's own result. `RESTORED.md` lists the files taken from the session log because the snapshot predates their last change. Testnet key material and personal paths were removed; nothing here was edited to fix the project. Re-install dependencies from the lockfile before running.
