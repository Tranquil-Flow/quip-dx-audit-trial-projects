## Trial card

- **Model:** GPT-6.
- **What it does:** A TypeScript CLI that creates two throwaway owner accounts and two SHRINCS Quip wallets, deploys them through the Quip wallet factory on Base Sepolia, funds them, and runs a same-chain native-ETH swap (1000 wei against 2000 wei): each wallet commits through `execute`, then one permissionless claim settles both legs. It keeps resumable state in a file.
- **Quip products and integration:** QuipSwap (`quip-swap-sdk`) and Quip SHRINCS smart wallets (`ethereum-sdk`) — NATIVE, live on Base Sepolia. Gas came from a third-party faucet, which both independent rebuilds tagged FALLBACK for the gas step; the builder said so openly.
- **Evidence:** We checked all 9 of the builder's Base Sepolia transactions (all status 1), including the claim [0xfa676cf13de28fd1fbd2283678fa1c09ec02d686b47eca8f11bd4da9684ad0ce](https://base-sepolia.blockscout.com/tx/0xfa676cf13de28fd1fbd2283678fa1c09ec02d686b47eca8f11bd4da9684ad0ce) on the Omnibus [0xA7955981D5759a799267063110Be0F7AeCc26F8A](https://base-sepolia.blockscout.com/address/0xA7955981D5759a799267063110Be0F7AeCc26F8A), and the final wallet balances (100000000002000 and 100000000001000 wei). First rebuild: works. It made a new run with its own keys on Base Sepolia, ending in claim [0xaebf691758882a3e521e524fc8c02e660c5a3148464450e3b57289bc6f88dc6e](https://base-sepolia.blockscout.com/tx/0xaebf691758882a3e521e524fc8c02e660c5a3148464450e3b57289bc6f88dc6e) with the swap settled. To get there it raised the script's faucet mining timeout from 8 to 30 minutes and did one owner-to-owner transfer by hand because of RPC lag. Second rebuild: works. With its own new keys it deployed two Quip wallets, committed from each and settled the swap live on Base Sepolia, claim [0x8851c849bcad20f99ba0305a7cb0c3d0d39aabd862cec9661ce3d37f1615f6c2](https://base-sepolia.blockscout.com/tx/0x8851c849bcad20f99ba0305a7cb0c3d0d39aabd862cec9661ce3d37f1615f6c2); its first faucet run failed only because the third-party faucet's balance update lagged.
- **Time:** 66 min.
- **What got in the way:** The docs say no swap SDK is published [[C-SWP-03](https://developers.quip.network/docs/getting-started/quip-sdk#:~:text=no%20swap%20SDK%20is%20published%20today)]. The SDK README links a usage file that is not shipped and no wallet-to-swap recipe exists [[C-SWP-05](https://cdn.jsdelivr.net/npm/@quip.network/quip-swap-sdk@0.1.0-beta.9/README.md#:~:text=For%20integration%20instructions%20and%20end-to-end%20walkthroughs), [C-TRL-15](https://developers.quip.network/docs/quip-interlock-protocol/quipswap)]. The npm registry metadata carries no README text [[C-R5-01](https://registry.npmjs.org/@quip.network%2fquip-swap-sdk)]. The Quip Accounts SDK has the local-signer problem [[C-ACC-06](https://cdn.jsdelivr.net/npm/@quip.network/ethereum-sdk@0.3.0-beta.8/dist/src/v1/shrincs/shrincsFactoryClient.d.ts)], and `createShrincsWallet` returns no transaction hash [[C-TRL-09](https://cdn.jsdelivr.net/npm/@quip.network/ethereum-sdk@0.3.0-beta.8/dist/src/v1/shrincs/shrincsFactoryClient.d.ts)]. Quip's only documented faucet is Aglais, which cannot fund a Base Sepolia swap, and the SDK has no Aglais deployment [[C-ACC-03](https://developers.quip.network/llms.txt#:~:text=Dispenses%2010%20AGLS%2C%20rate%2Dlimited%20per%20destination), [C-SWP-02](https://cdn.jsdelivr.net/npm/@quip.network/quip-swap-sdk@0.1.0-beta.9/dist/index.js)]. OP Sepolia is listed as deployed but lacks the wallet implementation [[C-ACC-02](https://cdn.jsdelivr.net/npm/@quip.network/ethereum-sdk@0.3.0-beta.8/dist/src/v1/addresses.js)]. The default 1800 s buffer is undocumented and 120 s windows were too short for PQ signing [[C-SWP-10](https://cdn.jsdelivr.net/npm/@quip.network/quip-swap-sdk@0.1.0-beta.9/dist/index.d.ts)]. No public source repository exists [[C-SWP-06](https://www.npmjs.com/package/@quip.network/quip-swap-sdk?activeTab=versions)].

## About this branch

This branch contains the project as the agent left it, minus dependencies, keys and vendored clones (see `EXCLUDED.md`). The agent worked in a temporary directory that was later deleted; the project was recovered from the agent runner's file snapshots and its session log. Where a later rebuild run had changed or added files, those were put back or removed, so the branch shows the trial's own result. Testnet key material and personal paths were removed; nothing here was edited to fix the project. Re-install dependencies from the lockfile before running.
