Observed confusions and blockers, with URLs and screen wording, will be recorded here.

- https://developers.quip.network/docs/compute/qvrf — product promises callback-based smart-contract randomness, but docs explicitly say “This page covers concepts only. The request interface is not yet final, so no function names or parameters appear here.” Expected contract address, ABI, fees, callback semantics; none available. Screenshot /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0008.png.
- Same URL — the name “QVRF” suggests a cryptographic VRF, yet docs explicitly say “QVRF is not a VRF” and V0 delivery is operator-trusted; verification only after delivery. A loot game could otherwise assume immediate on-chain proof verification. Screenshots /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0008.png and /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0010.png.
- Same URL — “Integration documentation with installable packages and code examples will follow” and fee model undecided; no testnet walkthrough to execute. Screenshot /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0011.png.
- https://quip.network/qvrf/ — first CTA “Request Access” rather than developer quickstart; sample transcript appears as illustrative UI, not a callable endpoint. Screenshot /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0005.png.
- https://developers.quip.network/docs/getting-started/quickstart — page says “we are building out the smart contract layer so you can take advantage of the quantum computers too”; as a Solidity developer expecting a live QVRF integration I cannot equate the EVM testnet with a production QVRF contract. Screenshot /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0017.png.

Faucet says browser calls refused, but offers a browser form as intermediary. Screenshots /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0028.png, /private/tmp/qbrowse/v6-gpt-6-sol-r6/shots/0030.png.

Expected a file under project `./keys`; had to repeat using an absolute project path and request fresh test tokens. Did not inspect or modify any possible file outside project; location of first key remains unknown.
