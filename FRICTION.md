Select all squares containing a duck,” HTTP 202. Browser's numbered controls did not label image tiles. Switched search engine.
- `https://www.google.com/search?...` (`0008.png`): “Our systems have detected unusual traffic from your computer network,” HTTP 429, instead of results. Bing (`0013.png`, `0017.png`, `0027.png`) showed Salesforce Quip, toothbrushes, then PayPal forums for the exact quoted blockchain terms, rather than vendor docs. Brave (`0021.png`) asked to “Drag the slider”; Ecosia (`0023.png`) and Mojeek (`0031.png`) blocked traffic; Startpage (`0028.png`) suspended access; Yahoo (`0022.png`) returned HTTP 500. The search-first workflow was a dead end until guessing `quip.network` directly.

- `https://developers.quip.network/docs/getting-started/quickstart` (`0035.png`, `0036.png`): labeled “Quickstart,” but primary actions are running a node or generating keys, without a short hello-world compute snippet; had to find a separate job guide. `https://developers.quip.network/docs/getting-started/quip-sdk` (`0038.png`, `0039.png`): plain `npm install` resolves old 2025 signature builds; package `@quip.network/sdk` does not exist yet, forcing prerelease/version care.
- `https://developers.quip.network/docs/compute/submit-a-job` (`0040.png`, `0041.png`): `xquad[quip]` needs Python 3.13+ while macOS system `python3` here was 3.9.6; had to find Homebrew Python and use a venv. `0043.png` points at `~/.quip/keystore.json` by default; for safe throwaway testing must remember to override with project-local `./keys/` path. `0045.png` showed manual `curl` faucet alternative, but SDK auto-faucet is cleaner.
- `https://developers.quip.network/docs/compute/submit-a-job` (`0043.png`, `0044.png`) and `https://developers.quip.network/docs/xquad/solving/quip-first-job` (`0048.png`): the tiny documented example gives an allowed-value warning, and my small project model triggered 5 similar warnings (`h[0] = 750 milli`). Expected beginner-friendly coefficients with no warnings; the SDK said it accepts/rescales and completed successfully, but the warning looks alarming for a first demo.
- `https://developers.quip.network/docs/xquad/solving/quip-first-job` (`0049.png`, `0050.png`): after “Submitting Aglais testnet job...” there is no progress until finality; job output lacks tx hash or explorer URL, only an order ID. Expected real-time job status and clickable proof for a hackathon demo. `best_energy_milli` differs from `result.energy` because chain uses SPIN milli-scale; easy to mistake for mismatched energy until reading `0050.png`.
