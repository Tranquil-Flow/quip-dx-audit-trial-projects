## Where two Quip products did not fit together (summary)
1. **Quip "testnet" (Aglais, chain 20033, curl faucet) vs. where QuipSwap/Quip Accounts actually live (Base/OP Sepolia, no Quip faucet).** llms.txt advertises the first as "the testnet"; Omnibus/WalletFactory/SHRINCS contracts have no code on it. A developer following "use the testnet faucet" gets funds on a chain where nothing in this task exists.
2. **Docs vs. SDK on swap SDK existence**: quip-sdk doc page says `@quip.network/quip-swap`/`sdk` don't exist and "use the wallet"; llms.txt links `@quip.network/quip-swap-sdk` which exists (beta). Dist-tag trap: `latest` = beta.6, `beta` = beta.9.
3. **Docs vs. contract on who can initiate**: quipswap doc says only Quip wallet contracts can initiate; contract/SDK have a permissionless keyed (ERC-7913) route (verified live via eth_call).
4. **Two SHRINCS signing surfaces**: `hashsigs-wasm` (`keygen/sign/verify`, raw 32-byte, stateful key object) vs `ethereum-sdk` `ShrincsSigner/ShrincsKeyPair` (HD derived, action-context hashes, on-chain leaf tracking). Nothing says how to sign an *arbitrary* off-chain message (e.g. an order) safely alongside a wallet's key; `signStatefulRawAt` would burn a leaf the wallet doesn't track.
5. **Glue nobody ships**: turning an Omnibus `Call` (quip-swap-sdk `prepareCommit`) into `ShrincsWalletClient.execute` (ethereum-sdk) works but is undocumented; native-leg `value` is paid by the sending EOA, not the wallet.
6. **ethereum-sdk is browser-wallet-shaped** (`account: Address`), not usable with a local key on a plain RPC without patching; and the beta package has no root export (subpaths only).
7. **Source of truth is scattered**: GitHub/GitLab `main` of ethereum-sdk & hashsigs-solidity are the OLD WOTS+ generation; current code is on unnamed branches (`deploy/testnet`, `feat/verifier-ERC7913`) or only in npm tarballs; USAGE.md/ARCHITECTURE.md referenced by swap-sdk README aren't in the tarball; ethereum-sdk README has an internal "Contact Rick first" note.
8. No docs page lists Base Sepolia RPC / chain ids / addresses for QuipSwap (found only in `deployments.json` inside the npm tarball).
